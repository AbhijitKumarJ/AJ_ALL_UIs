# Task Dissembler

This project provides functionality for dissembling, managing, and visualizing tasks in a hierarchical structure. It allows users to break down complex tasks into smaller, manageable sub-tasks and view them as a flowchart.

This project was derived from the `task_analyser` component of the `FullFastAPIBasedApp`.

## Usage

Open the `task_analyser/index.html` file in a web browser to use the application.
